# Third-party software

The browser chart uses Plotly.js, distributed under the MIT licence. `build_viewer.py` obtains the library from the installed Plotly Python package and preserves the licence header in the generated bundle. Plotly's licence is available in the installed package and at https://github.com/plotly/plotly.js/blob/master/LICENSE.

NumPy, Matplotlib and the optional imageio-ffmpeg package retain their respective licences. These notices do not assign a new licence to the coursework code.
